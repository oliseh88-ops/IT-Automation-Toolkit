# IT Automation Toolkit

A collection of Python tools built to practice IT automation, networking, troubleshooting, and system administration.

## Network Ping Checker

A Python-based network troubleshooting tool that checks whether a hostname or IP address is reachable.

### Features

- Checks whether a host is online or offline
- Sends ICMP ping requests
- Calculates packet loss
- Reports average network latency
- Accepts hostnames and IP addresses

### Technologies Used

- Python
- subprocess
- Regular Expressions (Regex)
- ICMP / Ping
- Command-line tools

### Example

Enter a website or IP address: youtube.com

===== NETWORK CHECK =====
Target: youtube.com
Status: ONLINE
Packet Loss: 0.0%
Average Latency: 97.494 ms
=========================
